# 🎭 CineMood AI | تشخیص احساسات با هوش مصنوعی

## 📌 معرفی پروژه

**CineMood AI** یک پروژهٔ هوش مصنوعی مبتنی بر یادگیری عمیق و بینایی ماشین است که با استفاده از تصاویر چهره، حالت‌های ظاهری صورت را در پنج دسته طبقه‌بندی می‌کند.

هدف این پروژه، توسعهٔ یک سیستم برای تشخیص حالت‌های چهره، تحلیل تصاویر و اجرای پیش‌بینی به‌صورت زنده با استفاده از وب‌کم است.

این پروژه در چارچوب یک چالش هوش مصنوعی توسعه داده شده است.

## ✨ قابلیت‌های پروژه

### ۱. تشخیص پنج حالت چهره

مدل آموزش‌دیده می‌تواند تصاویر چهره را در پنج دسته طبقه‌بندی کند:

- 😠 **Angry:** عصبانی
- 😀 **Happy:** خوشحال
- 😐 **Neutral:** خنثی
- 😢 **Sad:** غمگین
- 😮 **Surprise:** متعجب

### ۲. تشخیص زنده با وب‌کم

سیستم می‌تواند تصویر دریافتی از وب‌کم را در لحظه پردازش کند، چهره‌های قابل‌تشخیص را پیدا کند و نتیجهٔ پیش‌بینی مدل را روی تصویر نمایش دهد.

### ۳. تشخیص هم‌زمان چند چهره

یکی از قابلیت‌های توسعه‌یافتهٔ پروژه، امکان شناسایی چند چهره در یک فریم است.

در این بخش:
- چهره‌های موجود در تصویر شناسایی می‌شوند.
- هر چهره به‌صورت جداگانه برش داده و پردازش می‌شود.
- مدل برای هر چهره یک پیش‌بینی مستقل انجام می‌دهد.
- نتیجهٔ پیش‌بینی و میزان اطمینان مدل کنار هر چهره نمایش داده می‌شود.

این قابلیت امکان بررسی چند چهره را در یک تصویر یا نمای وب‌کم فراهم می‌کند.

### ۴. نمایش میزان اطمینان پیش‌بینی

سیستم علاوه بر نمایش دستهٔ پیش‌بینی‌شده، مقدار خروجی مدل مربوط به آن دسته را نیز نشان می‌دهد.

این مقدار بیانگر میزان اطمینان تخمینی مدل است و تضمین نمی‌کند که پیش‌بینی حتماً درست باشد.

### ۵. هموارسازی پیش‌بینی‌ها

برای کاهش تغییرات سریع خروجی در تصاویر متوالی، می‌توان پیش‌بینی‌های اخیر هر چهره را ذخیره و میانگین‌گیری کرد.

این روش ممکن است باعث پایدارتر شدن برچسب‌های نمایش‌داده‌شده شود؛ البته عملکرد آن به کیفیت مدل و شرایط تصویر بستگی دارد.

## 🧠 مدل هوش مصنوعی

در این پروژه از یک مدل یادگیری عمیق مبتنی بر شبکهٔ عصبی کانولوشنی (CNN) برای طبقه‌بندی تصاویر چهره استفاده می‌شود.

تصاویر ورودی بخش تشخیص زنده به تصاویر خاکستری با ابعاد ۴۸ در ۴۸ پیکسل تبدیل و مقادیر پیکسل‌ها به بازهٔ صفر تا یک نرمال‌سازی می‌شوند.

مدل آموزش‌دیده با استفاده از کتابخانهٔ Keras بارگذاری می‌شود و خروجی آن برای انتخاب یکی از پنج دستهٔ تعریف‌شده به کار می‌رود.

## 🛠️ فناوری‌ها و کتابخانه‌ها

- **Python:** زبان برنامه‌نویسی اصلی
- **TensorFlow / Keras:** ساخت، آموزش و اجرای مدل یادگیری عمیق
- **OpenCV:** پردازش تصاویر، دریافت فریم‌های وب‌کم و تشخیص چهره
- **NumPy:** پردازش آرایه‌ها و محاسبات عددی

## ⚙️ نصب و راه‌اندازی

ابتدا Python را نصب کنید و مخزن پروژه را دریافت کنید.

سپس در ترمینال، کتابخانه‌های موردنیاز بخش تشخیص چهره را نصب کنید:

```bash
pip install tensorflow keras opencv-python numpy
```

فایل مدل آموزش‌دیده را در مسیر مورد انتظار کد قرار دهید و مطمئن شوید وب‌کم به سیستم متصل است.

برای اجرای قابلیت تشخیص هم‌زمان چند چهره، دستور زیر را اجرا کنید:

```bash
python live_multi_face.py
```

برای بستن پنجرهٔ وب‌کم، کلید `q` را فشار دهید.

## 📊 ارزیابی مدل

ارزیابی یک مدل طبقه‌بندی فقط به دقت کلی محدود نمی‌شود. برای بررسی عملکرد این پروژه می‌توان از معیارهای زیر استفاده کرد:

- **Accuracy:** نسبت پیش‌بینی‌های صحیح به کل نمونه‌ها
- **Precision:** میزان صحت پیش‌بینی‌های مربوط به هر دسته
- **Recall:** میزان نمونه‌های هر دسته که مدل به‌درستی شناسایی می‌کند
- **F1-score:** میانگین هماهنگ Precision و Recall
- **Confusion Matrix:** نمایش دسته‌هایی که مدل ممکن است با یکدیگر اشتباه بگیرد

مقادیر واقعی این معیارها باید بر اساس نتایج ارزیابی مدل ثبت شوند.
