# 🎭 CineMood AI
## سامانه تشخیص احساسات چهره با هوش مصنوعی

### 📌 معرفی پروژه
پروژه CineMood AI یک سامانه مبتنی بر یادگیری عمیق است که برای تشخیص احساسات چهره از تصاویر و ورودی وب‌کم طراحی شده است.

هدف این پروژه، بررسی و پیاده‌سازی تشخیص احساسات با استفاده از هوش مصنوعی و شبکه‌های عصبی است.

### ✨ امکانات پروژه
- تشخیص احساسات از روی تصاویر
- تشخیص احساسات به‌صورت زنده با استفاده از وب‌کم
- استفاده از مدل یادگیری عمیق آموزش‌دیده
- نمایش نمودارهای آموزش مدل
- بررسی عملکرد مدل با استفاده از ماتریس درهم‌ریختگی

### 🧠 احساسات قابل تشخیص
مدل پروژه برای تشخیص پنج حالت احساسی طراحی شده است:

- خشم (Angry)
- شادی (Happy)
- حالت خنثی (Neutral)
- غم (Sad)
- تعجب (Surprise)

### 🛠️ فناوری‌های استفاده‌شده
- Python: زبان برنامه‌نویسی اصلی
- TensorFlow و Keras: ساخت و آموزش مدل یادگیری عمیق
- OpenCV: پردازش تصویر و دریافت تصویر از وب‌کم
- NumPy: انجام محاسبات عددی
- Matplotlib: رسم نمودارهای آموزشی
- Scikit-learn: ارزیابی عملکرد مدل

### 📂 فایل‌های پروژه
- `predict.py`: پیش‌بینی احساسات از روی تصویر
- `live_webcam.py`: تشخیص زنده احساسات با وب‌کم
- `mosabege.ipynb`: محیط آموزش و آزمایش مدل
- `model2_v2_69.keras`: فایل مدل آموزش‌دیده
- `confusion_matrix.png`: تصویر ماتریس درهم‌ریختگی
- `training_curves.png`: نمودارهای روند آموزش

### ▶️ نحوه اجرا

برای پیش‌بینی احساسات از روی تصویر، دستور زیر را در ترمینال اجرا کنید:

```bash
python predict.py
```

برای اجرای تشخیص احساسات با وب‌کم:

```bash
python live_webcam.py
```

پیش از اجرا، باید کتابخانه‌های موردنیاز پروژه نصب شده باشند.

### 🎯 هدف نهایی
هدف CineMood AI توسعه یک سامانه تشخیص احساسات چهره با استفاده از یادگیری عمیق و آشنایی عملی با کاربردهای هوش مصنوعی در پردازش تصویر است.

این پروژه در مسیر یادگیری، آزمایش و توسعه مدل‌های هوش مصنوعی تهیه شده است.
